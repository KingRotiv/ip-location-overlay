# IP Location Overlay

Uma extensão que exibe a localização de um endereço IP em um mapa interativo.

## Funcionalidades

- 🗺️ Visualização de localização de IP em mapa interativo
- 🔍 Busca rápida de endereços IP
- 📍 Exibição de coordenadas geográficas
- 🌐 Informações detalhadas do IP (país, cidade, ISP)
- ⚡ Interface responsiva e intuitiva

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/kingr/ip-location-overlay.git
```

2. Instale as dependências:
```bash
npm install
```

3. Carregue a extensão no navegador (modo desenvolvimento)

## Uso

1. Clique no ícone da extensão na barra de ferramentas
2. Digite um endereço IP válido
3. O mapa será exibido com a localização correspondente
4. Visualize informações adicionais sobre o IP

## Tecnologias Utilizadas

- JavaScript/HTML5/CSS3
- APIs de geolocalização de IP
- Mapas interativos (Leaflet/Google Maps)
